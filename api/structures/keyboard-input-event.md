- `type` string - The type of the event, can be `rawKeyDown`, `keyDown`, `keyUp` or `char`.
- `keyCode` string - The character that will be sent as the keyboard event. Should only use valid [Accelerator](../../tutorial/keyboard-shortcuts.md#accelerators) key codes.
